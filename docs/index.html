01 / Multi-engine analysis

五种证据，
同一个结论

不做单点判断。结构、规则、模型、相似度与签名各自给出证据， 强证据直接保留，弱证据需要互相印证——结论因此更稳，误报因此更少。

01
PE 文件解析Portable Executable
解析头部、节区、导入导出表与资源布局，识别异常节区、可疑 API 组合与加壳特征。
Structural
02
机器学习Dantrolene V1
细粒度特征与多成员融合模型，在本机完成推理；输出概率并参与证据交叉确认。
Model
03
YARA 规则Rule engine
内置规则集覆盖常见家族与行为特征，支持扩展；高危命中可直接作为确定性证据。
Signature-less
04
模糊哈希CTPH / Fuzzy
对同源变种做相似度比对，识别改壳、改字符串但保留核心结构的改写样本。
Similarity

03 / Real-time protection

落地即判定，
无需手动扫描

监控下载、桌面、文档与启动项。文件写入完成的那一刻，判定链已经在运行； 命中即阻断或隔离，无检出则放行并留下防复现记录。

Step 01

文件落地

浏览器下载、解压、复制或启动项写入，事件进入实时监控队列。

Step 02

多引擎并行

PE、ML、YARA、模糊哈希与签名库同时取证，按证据强度汇总。

Step 03

命中处置

确认威胁的文件被阻断或隔离；可疑对象等待确认，不静默放过。

Step 04

留痕与防复现

无检出也记录判定依据；同一来源再次出现时直接命中已知结论。

下载 / 桌面 / 文档 / 启动项 写入完成即触发 阻断 · 隔离 · 放行 全程本地
